# Deploy para Android — Os Farejadores

## 🚀 Opção 1: GitHub Pages (MAIS FÁCIL - Grátis)

### Passo 1: Criar uma Conta GitHub
1. Acesse https://github.com
2. Clique em "Sign up"
3. Preencha os dados (email, senha, nome de usuário)
4. Confirme seu email

### Passo 2: Criar um Repositório
1. Clique no ícone **+** no canto superior direito
2. Selecione **"New repository"**
3. Preencha:
   - **Repository name**: `os-farejadores`
   - **Description**: `RPG 2D de fantasia sombria amazônica`
   - **Public** (deixe marcado)
4. Clique **"Create repository"**

### Passo 3: Upload dos Arquivos
1. Na página do repositório, clique em **"Add file"** → **"Upload files"**
2. Arraste a pasta `os_farejadores` inteira (ou selecione os arquivos)
3. Clique em **"Commit changes"**

### Passo 4: Ativar GitHub Pages
1. Vá para **Settings** (engrenagem)
2. Procure por **"Pages"** no menu esquerdo
3. Em **"Source"**, selecione **"main"** (ou **"master"**)
4. Clique em **"Save"**
5. Aguarde alguns segundos

### Passo 5: Acessar no Android
1. Abra o navegador no seu Android
2. Acesse: `https://SEU_USUARIO.github.io/os-farejadores`
   - Exemplo: `https://joao123.github.io/os-farejadores`
3. **Pronto!** O jogo está online!

## 🌐 Opção 2: Netlify (Muito Fácil - Grátis)

### Passo 1: Criar Conta Netlify
1. Acesse https://netlify.com
2. Clique em **"Sign up"**
3. Escolha **"GitHub"** (mais fácil)
4. Autorize o Netlify a acessar sua conta GitHub

### Passo 2: Conectar Repositório
1. Clique em **"New site from Git"**
2. Selecione **"GitHub"**
3. Procure por `os-farejadores`
4. Clique para conectar

### Passo 3: Configurar Deploy
1. Em **"Build settings"**, deixe tudo padrão
2. Clique em **"Deploy site"**
3. Aguarde o deploy terminar (leva ~1 minuto)

### Passo 4: Acessar no Android
1. Abra o navegador no seu Android
2. Acesse a URL fornecida pelo Netlify
   - Exemplo: `https://os-farejadores-123.netlify.app`
3. **Pronto!** O jogo está online!

---

## ☁️ Opção 3: Vercel (Muito Fácil - Grátis)

### Passo 1: Criar Conta Vercel
1. Acesse https://vercel.com
2. Clique em **"Sign Up"**
3. Escolha **"Continue with GitHub"**
4. Autorize o Vercel

### Passo 2: Importar Projeto
1. Clique em **"New Project"**
2. Selecione **"Import Git Repository"**
3. Procure por `os-farejadores`
4. Clique em **"Import"**

### Passo 3: Deploy
1. Deixe as configurações padrão
2. Clique em **"Deploy"**
3. Aguarde o deploy terminar

### Passo 4: Acessar no Android
1. Abra o navegador no seu Android
2. Acesse a URL fornecida pelo Vercel
   - Exemplo: `https://os-farejadores.vercel.app`
3. **Pronto!** O jogo está online!

## 📱 Acessar no Android

### Via Navegador
1. **Abra o navegador** (Chrome, Firefox, etc.)
2. **Digite a URL** do jogo (GitHub Pages, Netlify ou Vercel)
3. **Aguarde carregar**
4. **Toque em "Iniciar Jornada"**

### Controles no Android
- **Setas virtuais**: Toque nas setas para mover (se aparecerem)
- **Botão de Ação**: Toque no botão para atacar/interagir
- **Teclado**: Se seu Android tiver teclado Bluetooth, use WASD + ESPAÇO

### Otimizar para Mobile
Se o jogo ficar lento no Android:
1. **Feche outras abas**
2. **Feche outros apps**
3. **Limpe o cache do navegador**
4. **Tente em outro navegador** (Chrome é mais rápido)

## 🔄 Atualizar o Jogo Online

Após fazer mudanças no código:

### GitHub Pages

### Netlify

3. Atualiza em ~1 minuto

### Vercel
1. Faça push do código para GitHub

3. Atualiza em ~1 minuto

## ⚠️ Problemas Comuns

### "Erro 404 - Página não encontrada"
- Verifique se a URL está correta
- Aguarde alguns minutos para o deploy terminar
- Recarregue a página (F5 ou toque no botão de atualizar)

### "Jogo carrega mas está em branco"
- Aguarde mais tempo para carregar
- Verifique sua conexão de internet
- Tente em outro navegador

### "Controles não funcionam"
- Toque na tela do jogo para focar
- Tente com teclado Bluetooth
- Recarregue a página

### "Jogo muito lento no Android"
- Feche outros apps
- Reduza o brilho da tela
- Tente em outro navegador (Chrome é mais rápido)
- Considere usar um Android mais potente
